Offer gift wrap and a handwritten note at Checkout. The Gift Wrapping [Module](/concepts/modules) is meant to add a wrapping option, price it, and carry the instruction through to whoever packs the box.

Nothing here has been verified: pricing, [Checkout](/modules/checkout) behavior, how it lands on the [Order](/modules/orders), and how it reaches [Fulfillment](/modules/fulfillment) are all unproven. Read the source before you evaluate it.

**Source:** [`modules/gift-wrapping`](https://github.com/86d-app/86d/tree/main/modules/gift-wrapping) · **npm:** [`@86d-app/gift-wrapping`](https://www.npmjs.com/package/@86d-app/gift-wrapping)

## Installation

```sh
86d module add gift-wrapping
```
