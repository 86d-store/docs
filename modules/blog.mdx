The Blog [Module](/concepts/modules) runs the blog on your [Storefront](/concepts/storefront). Posts have drafts, scheduled publish dates, categories, authors, hero images, and excerpts. Post bodies are Markdown, rendered through the same MDX pipeline as the rest of the Storefront, so you can drop Module components into a post.

**Source:** [`modules/blog`](https://github.com/86d-app/86d/tree/main/modules/blog) · **npm:** [`@86d-app/blog`](https://www.npmjs.com/package/@86d-app/blog)

## Installation

```sh
86d module add blog
```

## Store endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/blog/posts` | List published posts (paginated) |
| `GET` | `/blog/posts/:slug` | Get a post |
| `GET` | `/blog/categories` | List categories |
| `GET` | `/blog/feed.rss` | RSS feed |

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/admin/blog` | All posts (drafts, scheduled, published) |
| `POST` | `/admin/blog` | Create a post |
| `PUT` | `/admin/blog/:id` | Update |
| `POST` | `/admin/blog/:id/publish` | Publish (or schedule) |

## Components

- `<BlogList />`
- `<BlogPost slug={slug} />`
- `<BlogCategoryList />`
