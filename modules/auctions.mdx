The Auctions [Module](/concepts/modules) turns selected products into time-limited auctions. [Customers](/resources/glossary#customer) place bids; the Module enforces the minimum bid increment, holds reserve prices, and notifies the winner when the auction closes. On confirmation, the winning bid becomes an [Order](/concepts/commerce-model).

**Source:** [`modules/auctions`](https://github.com/86d-app/86d/tree/main/modules/auctions) · **npm:** [`@86d-app/auctions`](https://www.npmjs.com/package/@86d-app/auctions)

## Installation

```sh
86d module add auctions
```

## Store endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/auctions` | Active auctions |
| `GET` | `/auctions/:id` | Auction detail |
| `POST` | `/auctions/:id/bid` | Place a bid |

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/admin/auctions` | Create an auction |
| `POST` | `/admin/auctions/:id/end` | Force-close |
