</Warning>

The Square [Module](/concepts/modules) implements the current `PaymentProvider` interface from the [Payments Module](/modules/payments) using the Square Payments API. Its [Webhook](/resources/glossary#webhook) uses Square's notification URL and request-body signature scheme.

**Source:** [`modules/square`](https://github.com/86d-app/86d/tree/main/modules/square) · **npm:** [`@86d-app/square`](https://www.npmjs.com/package/@86d-app/square)

## Installation

```sh
86d module add square payments
```

## Configuration

Add the Module to `config.json`, then set the `SQUARE_*` environment variables. Do not put the access token in source or `config.json`. See [Environment variables](/configuration/environment-variables).

## Webhook setup

In the [Square Developer dashboard](https://developer.squareup.com/apps), open your application, go to **Webhooks**, and create a subscription for `payment.created` and `payment.updated` pointing at:

```text
POST https://your-store.com/api/square/webhook
```
