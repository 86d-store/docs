The Import / Export [Module](/concepts/modules) moves catalog and [Customer](/resources/glossary#customer) data in bulk. It accepts CSV and JSON on import and exports the same data in either format. Use it for migrations, supplier feed ingestion, and ad-hoc data work.

**Source:** [`modules/import-export`](https://github.com/86d-app/86d/tree/main/modules/import-export) · **npm:** [`@86d-app/import-export`](https://www.npmjs.com/package/@86d-app/import-export)

## Installation

```sh
86d module add import-export
```

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/admin/import` | Import (specify entity type) |
| `GET` | `/admin/export?type=` | Export |
| `GET` | `/admin/import/:id/status` | Job status for a long-running import |
