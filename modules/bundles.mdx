</Warning>

The Bundles [Module](/concepts/modules) groups multiple products into a single SKU sold at a discount. You can price a bundle at a fixed amount or at a percentage off the sum of its components. Selling a bundle deducts [Inventory](/modules/inventory) from each component, and bundle availability follows whichever component has the least stock.

**Source:** [`modules/bundles`](https://github.com/86d-app/86d/tree/main/modules/bundles) · **npm:** [`@86d-app/bundles`](https://www.npmjs.com/package/@86d-app/bundles)

## Installation

```sh
86d module add bundles
```

## Store endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/bundles` | List active bundles |
| `GET` | `/bundles/:slug` | Get a bundle with its components |

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/admin/bundles` | List bundles |
| `POST` | `/admin/bundles` | Create |
| `PUT` | `/admin/bundles/:id` | Update |
| `DELETE` | `/admin/bundles/:id` | Delete |
