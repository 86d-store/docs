</Warning>

The Recently Viewed [Module](/concepts/modules) records every product detail page a [Shopper](/resources/glossary#shopper) visits and shows those products in a carousel. State is stored per browser for [Guests](/resources/glossary#guest) and merged into the [Customer](/resources/glossary#customer) record on sign-in.

**Source:** [`modules/recently-viewed`](https://github.com/86d-app/86d/tree/main/modules/recently-viewed) · **npm:** [`@86d-app/recently-viewed`](https://www.npmjs.com/package/@86d-app/recently-viewed)

## Installation

```sh
86d module add recently-viewed
```

## Configuration

```ts
recentlyViewed({
  maxItems: "20",
  retentionDays: "30",
});
```

## Store endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/recently-viewed/track` | Record a view |
| `GET` | `/recently-viewed/me` | Get the current Shopper's list |

## Components

- `<RecentlyViewed />`: horizontal carousel; fetches its own data.
