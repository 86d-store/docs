The Quotes [Module](/concepts/modules) turns the cart into a request-for-quote (RFQ) for B2B selling. A [Customer](/resources/glossary#customer) fills a [Cart](/modules/cart), clicks **Request quote** instead of **Checkout**, and the merchant receives the request with line items, customer details, and notes. The merchant responds with a price, an optional discount, and an expiry date; the Customer can then accept or reject the quote.

**Source:** [`modules/quotes`](https://github.com/86d-app/86d/tree/main/modules/quotes) · **npm:** [`@86d-app/quotes`](https://www.npmjs.com/package/@86d-app/quotes)

## Installation

```sh
86d module add quotes
```

## Store endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/quotes/request` | Submit a quote request |
| `GET` | `/quotes/me` | List the customer's quotes |
| `POST` | `/quotes/me/:id/accept` | Accept a quoted price (creates an order) |

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/admin/quotes` | List quote requests |
| `POST` | `/admin/quotes/:id/respond` | Send a quote with price and expiry |
| `POST` | `/admin/quotes/:id/reject` | Reject |
