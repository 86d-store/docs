</Warning>

The Waitlist [Module](/concepts/modules) lets [Shoppers](/resources/glossary#shopper) join a waitlist for any product. When the product becomes available (a preorder window opens or a backorder is replenished), the Module fires a `waitlist.notify` event for each subscriber.

**Source:** [`modules/waitlist`](https://github.com/86d-app/86d/tree/main/modules/waitlist) · **npm:** [`@86d-app/waitlist`](https://www.npmjs.com/package/@86d-app/waitlist)

## Installation

```sh
86d module add waitlist
```

## Components

Use these components in your MDX [Template](/concepts/templates) files.

- `<WaitlistButton productId={id} />`
- `<WaitlistForm productId={id} />`
