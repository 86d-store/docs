<Warning>
  **Experimental.** This Module has no test or production evidence recorded yet. Read it, run it locally, and hold off on real Orders. See [maturity levels](/resources/versioning).
</Warning>

Sell on Facebook without keeping a second catalog by hand. The Facebook Shop [Module](/concepts/modules) is meant to publish your [Products](/modules/products) to a Facebook commerce catalog and bring what sells back into your [Orders](/modules/orders).

Nothing here has been verified: catalog publishing, [Inventory](/modules/inventory) sync, Order ingestion, the provider approval process, and provider events are all unproven. Read the source before you evaluate it.

**Source:** [`modules/facebook-shop`](https://github.com/86d-app/86d/tree/main/modules/facebook-shop) · **npm:** [`@86d-app/facebook-shop`](https://www.npmjs.com/package/@86d-app/facebook-shop)

## Installation

```sh
86d module add facebook-shop
```
