The Gift Registry [Module](/concepts/modules) lets [Customers](/resources/glossary#customer) build registries for weddings, babies, birthdays, and other milestones. Each registry has a public share link. Gift-givers see what the owner wants and what has already been bought, and quantity tracking prevents duplicate gifts.

**Source:** [`modules/gift-registry`](https://github.com/86d-app/86d/tree/main/modules/gift-registry) · **npm:** [`@86d-app/gift-registry`](https://www.npmjs.com/package/@86d-app/gift-registry)

## Installation

```sh
86d module add gift-registry
```

## Store endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/registries/me` | List the customer's registries |
| `POST` | `/registries/me` | Create a registry |
| `POST` | `/registries/me/:id/items` | Add an item |
| `GET` | `/registries/share/:token` | Public registry view |
