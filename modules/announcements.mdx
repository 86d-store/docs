The Announcements [Module](/concepts/modules) shows banners and popups across the [Storefront](/concepts/storefront). Each announcement has a schedule with a start and an end, targeting rules for geography and Customer group, and a dismissal policy.

**Source:** [`modules/announcements`](https://github.com/86d-app/86d/tree/main/modules/announcements) · **npm:** [`@86d-app/announcements`](https://www.npmjs.com/package/@86d-app/announcements)

## Installation

```sh
86d module add announcements
```

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/admin/announcements` | Create an announcement |
| `PUT` | `/admin/announcements/:id` | Update an announcement |
