</Warning>

The Product Labels [Module](/concepts/modules) attaches badges to product cards, driven by rules you configure (newness window, on-sale flag, low-stock threshold) or by manual selection. Labels render through `<ProductCard />` automatically when the Module is enabled.

**Source:** [`modules/product-labels`](https://github.com/86d-app/86d/tree/main/modules/product-labels) · **npm:** [`@86d-app/product-labels`](https://www.npmjs.com/package/@86d-app/product-labels)

## Installation

```sh
86d module add product-labels
```

## Configuration

```ts
productLabels({
  newWindowDays: "30",
  bestSellerThreshold: "100",
});
```

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/admin/product-labels` | List configured labels |
| `POST` | `/admin/product-labels` | Create a label |
| `PUT` | `/admin/product-labels/:id` | Update a label |
| `DELETE` | `/admin/product-labels/:id` | Delete a label |
