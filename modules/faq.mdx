The FAQ [Module](/concepts/modules) manages a self-service knowledge base on your [Storefront](/concepts/storefront). You can group questions under headings such as "Shipping", "Returns", and "Account", embed them on product detail pages, or publish them as a standalone `/faq` page. Search is built in.

**Source:** [`modules/faq`](https://github.com/86d-app/86d/tree/main/modules/faq) · **npm:** [`@86d-app/faq`](https://www.npmjs.com/package/@86d-app/faq)

## Installation

```sh
86d module add faq
```

## Store endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/faq` | All approved questions, grouped |
| `GET` | `/faq/search?q=` | Search the FAQ |

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/admin/faq` | Create |
| `PUT` | `/admin/faq/:id` | Update |

## Components

- `<FaqList />`
- `<FaqGroup slug={slug} />`
- `<FaqSearch />`
