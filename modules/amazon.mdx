</Warning>

The Amazon [Module](/concepts/modules) connects your [Store](/resources/glossary#store) to Amazon Marketplace through Amazon's Selling Partner API (SP-API). It supports both FBA (Fulfilled by Amazon) and FBM (Fulfilled by Merchant). Listings sync from your catalog with ASIN mapping, and Amazon [Orders](/concepts/commerce-model) land in your `@86d-app/orders` queue with `channel: "amazon"`.

**Source:** [`modules/amazon`](https://github.com/86d-app/86d/tree/main/modules/amazon) · **npm:** [`@86d-app/amazon`](https://www.npmjs.com/package/@86d-app/amazon)

## Installation

```sh
86d module add amazon
```

## Configuration

```ts
amazon({
  sellerId: "A1B2C3D4E5F6G7",
  refreshToken: "...",
  region: "NA",                  // "NA" | "EU" | "FE"
  marketplaceId: "ATVPDKIKX0DER",
});
```

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/admin/amazon/listings` | List Amazon listings |
| `POST` | `/admin/amazon/listings` | Create a listing |
| `POST` | `/admin/amazon/inventory/sync` | Push inventory |
| `GET` | `/admin/amazon/orders` | Amazon orders |
