</Warning>

The Backorders [Module](/concepts/modules) lets [Shoppers](/resources/glossary#shopper) buy items that are temporarily out of stock. It tags each backordered line item with an estimated ship date, then emits `backorder.fulfillable` once stock is replenished and the [Order](/concepts/commerce-model) can ship.

**Source:** [`modules/backorders`](https://github.com/86d-app/86d/tree/main/modules/backorders) · **npm:** [`@86d-app/backorders`](https://www.npmjs.com/package/@86d-app/backorders)

## Installation

```sh
86d module add backorders
```

## Configuration

```ts
backorders({
  defaultLeadTimeDays: "21",
  notifyCustomerOnFulfillable: "true",
});
```

## Components

- `<BackorderBadge productId={id} />`: [Storefront](/concepts/storefront) badge with the expected ship date
