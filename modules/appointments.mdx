Book time instead of shipping a box. The Appointments [Module](/concepts/modules) is for a Store that sells consultations, fittings, repairs, classes, or any service where the thing being bought is a slot on a calendar.

Nothing here has been verified: booking, calendar handling, [Checkout](/modules/checkout), notifications, and provider behavior are all unproven. Read the source before you evaluate it.

**Source:** [`modules/appointments`](https://github.com/86d-app/86d/tree/main/modules/appointments) · **npm:** [`@86d-app/appointments`](https://www.npmjs.com/package/@86d-app/appointments)

## Installation

```sh
86d module add appointments
```
