The PayPal [Module](/concepts/modules) implements the current `PaymentProvider` interface from the [Payments Module](/modules/payments) using the PayPal REST Orders API. It verifies configured [Webhook](/resources/glossary#webhook) events through PayPal's verification API.

**Source:** [`modules/paypal`](https://github.com/86d-app/86d/tree/main/modules/paypal) · **npm:** [`@86d-app/paypal`](https://www.npmjs.com/package/@86d-app/paypal)

## Installation

```sh
86d module add paypal payments
```

## Configuration

Add the Module to `config.json`, then set the `PAYPAL_*` environment variables. Do not put the client secret in source or `config.json`. See [Environment variables](/configuration/environment-variables).

## Webhook setup

Set the webhook URL in the [PayPal developer dashboard](https://developer.paypal.com/dashboard/) to:

```text
POST https://your-store.com/api/paypal/webhook
```

Subscribe to `PAYMENT.CAPTURE.COMPLETED` and `PAYMENT.CAPTURE.DENIED` at minimum.
