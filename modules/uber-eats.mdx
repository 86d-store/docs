The Uber Eats [Module](/concepts/modules) connects your [Store](/resources/glossary#store) to the Uber Eats marketplace. It syncs your catalog as a menu and ingests Uber Eats [Orders](/concepts/commerce-model) into the same `@86d-app/orders` queue you use for direct-store Orders; a `channel` field records where each Order came from.

**Source:** [`modules/uber-eats`](https://github.com/86d-app/86d/tree/main/modules/uber-eats) · **npm:** [`@86d-app/uber-eats`](https://www.npmjs.com/package/@86d-app/uber-eats)

## Installation

```sh
86d module add uber-eats
```

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/admin/uber-eats/menu/sync` | Push catalog as a menu |
| `GET` | `/admin/uber-eats/orders` | Uber Eats orders |
