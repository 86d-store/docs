The Sitemap [Module](/concepts/modules) generates `sitemap.xml` from the active catalog (products, collections, pages, blog posts) and serves it at `/sitemap.xml`. It also generates `robots.txt` with sensible defaults: allow public pages, disallow the [Store Admin](/concepts/admin) and API routes, and point search engines at the sitemap.

**Source:** [`modules/sitemap`](https://github.com/86d-app/86d/tree/main/modules/sitemap) · **npm:** [`@86d-app/sitemap`](https://www.npmjs.com/package/@86d-app/sitemap)

## Installation

```sh
86d module add sitemap
```

## Store endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/sitemap.xml` | Sitemap index |
| `GET` | `/robots.txt` | Robots policy |
