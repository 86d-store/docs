</Warning>

Somewhere to write down what happened with an Order. The Order Notes [Module](/concepts/modules) is meant to hold internal notes your team can see and, separately, notes a [Customer](/modules/customers) is allowed to see.

Nothing here has been verified: who can see which note, authorization, retention, and how notes attach to an [Order](/modules/orders) are all unproven. Getting the visibility boundary wrong here shows internal notes to a Shopper, so read the source before you evaluate it.

**Source:** [`modules/order-notes`](https://github.com/86d-app/86d/tree/main/modules/order-notes) · **npm:** [`@86d-app/order-notes`](https://www.npmjs.com/package/@86d-app/order-notes)

## Installation

```sh
86d module add order-notes
```
