<Warning>
  **Experimental.** This Module has no test or production evidence recorded yet. Read it, run it locally, and hold off on real Orders. See [maturity levels](/resources/versioning).
</Warning>

Sell through TikTok Shop without running a separate storefront. The TikTok Shop [Module](/concepts/modules) is meant to list your [Products](/modules/products), keep stock in step, and pull sales back into your [Orders](/modules/orders).

Nothing here has been verified: listings, [Inventory](/modules/inventory), Orders, refunds, [Fulfillment](/modules/fulfillment), and provider events are all unproven. A marketplace that sells stock you no longer have is the expensive failure, so read the source before you evaluate it.

**Source:** [`modules/tiktok-shop`](https://github.com/86d-app/86d/tree/main/modules/tiktok-shop) · **npm:** [`@86d-app/tiktok-shop`](https://www.npmjs.com/package/@86d-app/tiktok-shop)

## Installation

```sh
86d module add tiktok-shop
```
