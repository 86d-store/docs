</Warning>

The Automations [Module](/concepts/modules) is a rule engine: when a trigger fires and its conditions match, the rule runs its actions. Triggers are domain events that other Modules emit, such as `order.placed` or `customer.created`. Actions can send an email, tag a [Customer](/resources/glossary#customer), issue store credit, or call an external webhook.

**Source:** [`modules/automations`](https://github.com/86d-app/86d/tree/main/modules/automations) · **npm:** [`@86d-app/automations`](https://www.npmjs.com/package/@86d-app/automations)

## Installation

```sh
86d module add automations
```

## Admin endpoints

| Method | Path | Description |
