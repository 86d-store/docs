The Toast [Module](/concepts/modules) connects your [Store](/resources/glossary#store) to a Toast POS for restaurants and cafes. Your catalog syncs to Toast as a menu, and online [Orders](/concepts/commerce-model) route to Toast for in-restaurant fulfillment. Toast in-store sales can flow back into `@86d-app/orders`, so you can report on online and in-store sales together.

**Source:** [`modules/toast`](https://github.com/86d-app/86d/tree/main/modules/toast) · **npm:** [`@86d-app/toast`](https://www.npmjs.com/package/@86d-app/toast)

## Installation

```sh
86d module add toast
```

## Configuration

Set the `TOAST_*` environment variables (`TOAST_API_KEY`, `TOAST_RESTAURANT_GUID`, `TOAST_SANDBOX`). See [Environment variables](/configuration/environment-variables).
