The Settings [Module](/concepts/modules) is a typed key/value store for configuration that applies to the whole [Store](/resources/glossary#store). Choices scoped to one [Template](/concepts/templates) live in `config.json` instead. Each setting has a key, a typed value, and optional metadata so it renders as a form field on the right [Store Admin](/concepts/admin) page.

Most other Modules read their changeable preferences from Settings.

**Source:** [`modules/settings`](https://github.com/86d-app/86d/tree/main/modules/settings) · **npm:** [`@86d-app/settings`](https://www.npmjs.com/package/@86d-app/settings)

## Installation

```sh
86d module add settings
```

## Admin endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/admin/settings/:key` | Read |
| `PUT` | `/admin/settings/:key` | Write |
