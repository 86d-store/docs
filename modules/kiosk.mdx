<Warning>
  **Experimental.** Public kiosk sessions and commerce actions are unavailable. Do not use this module to accept real orders. See [maturity levels](/resources/versioning).
</Warning>

The Kiosk [module](/concepts/modules) currently supports station registration and inspection of stored legacy session lifecycle records. Every displayed session status is explicitly prefixed with `legacy-`, and item, price, tax, tip, payment, and order fields are not exposed as current commerce facts.

The public terminal is a static unavailable surface. It cannot start or update a session, select items, report station health, calculate prices, invoke [Checkout](/modules/checkout) or [Payment](/modules/payments), create an order, or delete a station. Those paths remain absent until complete authoritative Workflows own them.

**Source:** [`modules/kiosk`](https://github.com/86d-app/86d/tree/main/modules/kiosk) · **npm:** [`@86d-app/kiosk`](https://www.npmjs.com/package/@86d-app/kiosk)

## Installation

```sh
86d module add kiosk
```

Installing the module does not enable public ordering or point-of-sale behavior.
